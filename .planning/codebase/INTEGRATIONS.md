# External Integrations

**Analysis Date:** 2026-05-12

## APIs and External Services

### Cucumber Messages Protocol

- **What it is:** Wire protocol for BDD test execution events (scenario started, step passed/failed, etc.)
- **SDK/Client:**
  - `cucumber-messages` (Python package) -- Python bindings for message types
  - `@cucumber/pretty-formatter` (Node.js npm package) -- Terminal formatter output
  - `@cucumber/html-formatter` (Node.js npm package) -- HTML report generation
- **Transport:** NDJSON over file/stdout/execnet channels
- **Schema source:** `https://github.com/cucumber/messages.git` (referenced in `src/pytest_bdd/script/sync_messages_contract_schemas.py:16`)
- **Local schemas:** Cached at `src/pytest_bdd/model/message_jsonschema/*.json`

Key Python imports using cucumber_messages throughout:
- `src/pytest_bdd/model/message_converter.py`
- `src/pytest_bdd/model/message_extension.py`
- `src/pytest_bdd/plugin/gherkin_message_reporter/lifecycle_runtime.py`
- `src/pytest_bdd/plugin/pickle_runner/entrypoint.py`

### Gherkin Parser (Go Shared Library)

- **What it is:** Compiled Go shared library for high-performance gherkin parsing
- **SDK/Client:** Custom ctypes bridge in `src/pytest_bdd/_gherkin_go/_bridge.py`
- **Source:** Go source at `gherkin_go/`, vendored dependencies from:
  - `github.com/cucumber/gherkin/go/v28` v28.0.0
  - `github.com/cucumber/messages/go/v24` v24.0.1 (indirect)
- **Build:** `go build -buildmode=c-shared` via `BuildGoCommand` (`src/pytest_bdd/_gherkin_go/_build.py`)
- **Fallback:** Python `gherkin-official>=33` package when Go library unavailable
- **Control env var:** `PYTEST_BDD_GHERKIN_BACKEND` (`auto`/`go`/`python`)
- **Platform libs:** `libgherkin_go.so` (Linux), `gherkin_go.dll` (Windows), `libgherkin_go.dylib` (macOS)

### Coverage Services

- **Codecov:**
  - Upload via `codecov` Python package (installed in CI, `.github/workflows/main.yml:72`)
  - Triggered on CI for Python 3.14 matrix runs only
  - Coverage data generated by `coverage` Python package

- **Coveralls:**
  - Upload via `python-coveralls` package (`Makefile:54-55`, `pyproject.toml:149`)
  - Used for local coverage reporting; CI prefers Codecov

### Package Registry: PyPI

- **Package name:** `pytest-bdd-ng` v2.3.1 (`pyproject.toml:81,84`)
- **Upload mechanism:** `twine` (`pyproject.toml:78-79`)
- **Build validation:** `twine check dist/*` in CI (`main.yml:83`)

### Read the Docs

## CI/CD and Deployment

### Hosting

### CI Pipeline (GitHub Actions)

**Main workflow** (`.github/workflows/main.yml`):
- **Triggers:** push, pull_request, workflow_dispatch
- **Matrix:** Python 3.10-3.14, pypy3.11 x ubuntu/windows/macos (18 combinations)
- **Timeout:** 30 minutes
- **Steps:**
  1. Checkout with recursive submodules (`gherkin_go/vendor/`)
  2. Setup Python (via `actions/setup-python@v5`)
  3. Setup Node.js (via `actions/setup-node@v4`, any version)
  4. Install pandoc (via `r-lib/actions/setup-pandoc@v2`)
  5. pip install tox, tox-gh-actions, codecov, uv
  6. npm install `@cucumber/html-formatter`, `cucumber-html-reporter`
  7. `uv run tox`
  8. Message schema sync check (3.14 + ubuntu only)
  9. Codecov upload (3.14 only)
  10. Build + twine check (3.14 only)

**Messages Baseline Drift workflow** (`.github/workflows/messages-baseline-drift.yml`):
- **Triggers:** Weekly cron (Monday 04:00 UTC), workflow_dispatch
- **Purpose:** Detect Cucumber Messages protocol capability drift
- **Output:** `baseline-diff.json` artifact

### Docker/Compose (Testing Only)

- **File:** `tests/e2e/fixtures/remote_xdist/docker-compose.yml`
- **Services:** controller, proxy, worker1, worker2
- **Images:** Built locally from `python:3.14-slim`
