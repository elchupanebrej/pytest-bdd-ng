## Problem

BDD test creation is not integrated into the standard development workflow. AGENTS.md does not include the development guide in agent context. ATDD/BDD is not part of active feature development, and ATDD/BDD tests are not included in the UAT (User Acceptance Testing) phase of any agentic workflow.

## Solution

1. Adapt AGENTS.md to always include the development guide (DEVELOPMENT.rst) into agent context
2. Make ATDD/BDD a mandatory part of active feature development workflow
3. Include ATDD/BDD tests as a required step in the UAT phase of all agentic workflows
