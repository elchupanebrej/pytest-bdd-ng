</risks>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pytest item -> launch JSON | Raw nodeid crosses from pytest collection into IDE-consumed JSON. |
| user feature/steps -> diagnostic JSON | User-authored text and source references cross into machine-readable attachments. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Tampering | launch nodeid tests | mitigate | Assert nodeid is JSON data and tests invoke it as one pytest argv element, never shell-compose it. |
| T-22-02 | Tampering | metadata isolation tests | mitigate | Assert launch metadata is not present in `Pickle.tags` and does not affect `-m` or tag hooks. |
| T-22-03 | Elevation | mock-run probes | mitigate | Probe files prove fixture bodies, step bodies, scenario hooks, and step hooks do not run in IDE bootstrap. |
| T-22-SC | Tampering | package installs | accept | No package-manager install task exists in this plan. |
</threat_model>
