<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CCK NDJSON download → local cache | External NDJSON files fetched from GitHub via gh API or urllib — untrusted network input |
| NDJSON content → converter | Parsed JSON lines fed to converter pipeline — malformed input possible |
| Docker container → report output | Docker-based Allure3 generates HTML files — container output written to filesystem |
| Playwright browser → rendered report | Browser automation validates HTML — DOM inspection of rendered content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-07 | Tampering | CCK NDJSON download | mitigate | Download from official cucumber/compatibility-kit repo only; verify tag matches CCK_RELEASE_TAG; cache by filename to prevent path traversal |
| T-20-08 | Denial of Service | CCK download utility | mitigate | Session-scoped caching prevents repeated downloads; timeout on gh API and urllib requests; graceful skip on download failure |
| T-20-09 | Tampering | Docker report generation | mitigate | Use pinned Docker image tag (frankescobar/allure-docker-service:2.27.0); output written to tmp_path (isolated per test) |
| T-20-10 | Information Disclosure | Playwright browser validation | accept | No PII processed; browser only reads locally-served HTML reports; no network exposure |
| T-20-11 | Spoofing | Converter output validation | mitigate | Assert specific file patterns (*-result.json, *-container.json) and required fields (name, status) to detect malformed output |
| T-20-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages (factoryboy, hypothesis — per RESEARCH.md audit) |

</threat_model>
