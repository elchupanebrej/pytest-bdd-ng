# Phase 30 Plan 02: Migrate Codebase to BLQ Import-Form Rules

## Objective

Finish Phase 30 by migrating the checked codebase to satisfy BLQ1506, BLQ1508, BLQ1509, BLQ1510, BLQ1511, and BLQ1512, then remove the temporary global disables for those rules from `pyproject.toml`. Phase 30 is not complete until `pre-commit run --all-files` passes with those rules enabled.

## Background

Plan 01 implemented and tested the BLQ15 checker family, but the execution left the stricter import-form rules globally disabled:

- `forbidden-star-import` (BLQ1506)
- `sibling-import-form` (BLQ1508)
- `prefer-module-import` (BLQ1509)
- `import-name-not-in-all` (BLQ1510)
- `attribute-not-in-all` (BLQ1511)
- `same-hierarchy-import` (BLQ1512)

That is not an acceptable final state for Phase 30. The checker rules exist to enforce repository policy, not to remain disabled after implementation.

## Tasks

### Task 1: Measure Current BLQ Import-Form Violations

**Type:** audit
**Files:** `pyproject.toml`, `src/pytest_bdd/_pylint/checkers/module_api_rules.py`

**Action:** Temporarily run Pylint with BLQ1506/1508/1509/1510/1511/1512 enabled and capture a complete violation inventory grouped by rule and package area.

**acceptance_criteria:**

- Inventory lists every active violation by rule symbol and file.
- Inventory separates true policy violations from checker false positives.
- Inventory is saved in Phase 30 artifacts or summarized in `30-SUMMARY.md`.

### Task 2: Migrate Star Imports

**Type:** refactor
**Files:** active `src/pytest_bdd/` modules reported by BLQ1506

**Action:** Replace every checked `from x import *` with explicit imports or module imports. Preserve runtime behavior and public `__all__` contracts.

**acceptance_criteria:**

- BLQ1506 is enabled in `pyproject.toml`.
- Pylint reports zero BLQ1506 violations.
- No local ignore is used unless the import is demonstrably generated or protocol-required, with an inline explanation.

### Task 3: Migrate Same-Package Absolute Imports

**Type:** refactor
**Files:** active `src/pytest_bdd/` modules reported by BLQ1508 and BLQ1512

**Action:** Convert same-package and same-hierarchy absolute imports to the required sibling/local form.

**acceptance_criteria:**

- BLQ1508 and BLQ1512 are enabled in `pyproject.toml`.
- Pylint reports zero BLQ1508 and BLQ1512 violations.
- Import cycles are not introduced.
- Public imports from `pytest_bdd` remain stable.

### Task 4: Migrate Direct Sibling Name Imports

**Type:** refactor
**Files:** active `src/pytest_bdd/` modules reported by BLQ1509

**Action:** Replace direct sibling name imports with module imports where the rule requires it, then qualify call sites through the imported module.

**acceptance_criteria:**

- BLQ1509 is enabled in `pyproject.toml`.
- Pylint reports zero BLQ1509 violations.
- The migration does not reduce readability for package facade `__init__.py` files; if the rule needs a checker refinement for facade modules, update the checker and tests instead of adding global disables.

### Task 5: Enforce `__all__` Import Contracts

**Type:** refactor
**Files:** active `src/pytest_bdd/` modules reported by BLQ1510 and BLQ1511

**Action:** Ensure local imports and module-attribute access only target names declared in the source module's `__all__`. Fix either the importer or the source module's `__all__`, depending on ownership.

**acceptance_criteria:**

- BLQ1510 and BLQ1511 are enabled in `pyproject.toml`.
- Pylint reports zero BLQ1510 and BLQ1511 violations.
- No module exposes implementation details in `__all__` merely to satisfy an importer; callers must use the intended public surface.

### Task 6: Remove Global Disables and Verify

**Type:** verify
**Files:** `pyproject.toml`, all touched source/test files

**Action:** Remove the temporary global disables for BLQ1506/1508/1509/1510/1511/1512 from `pyproject.toml`, run focused and full verification, and update Phase 30 artifacts.

**acceptance_criteria:**

- `pyproject.toml` does not disable BLQ1506, BLQ1508, BLQ1509, BLQ1510, BLQ1511, or BLQ1512 globally.
- Any remaining exception is local to the import site and has a specific explanation.
- `pre-commit run --all-files` exits 0.
- `pytest src/pytest_bdd_toolchain/case/unit/test_pylint_checkers.py --basetemp=/tmp/pytest-bdd-ng-checkers` exits 0.
- Public import smoke for `pytest_bdd`, scenario locators, pickle runner, lifecycle runtime, and struct BDD model exits 0.
