  <action>
    Create typing_rules.py following the exact _ruff/rules/ blueprint.

    **BLQ1101 — bare # type: ignore (ERROR):**
    Regex: `#\s*type:\s*ignore\s*$` (no error code in brackets)
    Finds lines where # type: ignore appears without [error-code]. This is the most critical rule — bare ignores mask ALL mypy errors on that line, including new errors from future mypy versions.
    Violation message: "BLQ1101: bare '# type: ignore' without error code at {path}:{line}. Add error code in brackets: '# type: ignore[error-code]'"

    **BLQ1102 — missing explanation (WARNING):**
    Regex: `#\s*type:\s*ignore\[.*?\]\s*$` (has error code but NO " — " explanation separator)
    Explanation format: `# type: ignore[error-code] — brief reason`
    The separator is " — " (space, em dash, space). Check for this pattern after the closing bracket.
    Violation message: "BLQ1102: '# type: ignore[{code}]' missing explanation at {path}:{line}. Add explanation: '# type: ignore[{code}] — brief reason'"

    **BLQ1103 — stale ignore (WARNING, optional):**
    Compares ignore codes against mypy output. If a # type: ignore[error-code] references an error code that mypy no longer reports for that line, the ignore is stale and should be removed.
    Implementation: run `mypy --show-error-codes` and cross-reference. If mypy produces zero errors for that line, the ignore is no longer needed.
    This is OPTIONAL — may be too expensive for pre-commit. Implement as a separate check that runs in CI only, or skip if too slow.

    Implementation structure:
    - Violation NamedTuple(path, line, message)
    - TYPE_IGNORE_BARE = re.compile(r'#\s*type:\s*ignore\s*$')
    - TYPE_IGNORE_NO_EXPLANATION = re.compile(r'#\s*type:\s*ignore\[[^\]]+\]\s*$')
    - TYPE_IGNORE_WITH_EXPLANATION = re.compile(r'#\s*type:\s*ignore\[([^\]]+)\]\s*—\s*(.+)$')
    - check_file(path) → list[Violation]: reads file line by line, applies regex, builds violations
    - main(argv) → int: walks target paths, collects violations, prints to stdout, returns 1 if violations

    Do not check files in stubs/, .planning/, or __pycache__. The rule applies to .py files only.
  </action>
