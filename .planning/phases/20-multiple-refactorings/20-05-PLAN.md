    Write the final two ADRs for the architecture phase.

    ADR-009 (feature-batch-parsing.md):
    - Context: Feature file parsing is I/O-bound; sequential parsing of 100s of .feature files is slow
    - Decision: Lazy-batched async parsing via FeatureBatchParser using asyncio + multiprocessing; flush on first get() call; optional aiofiles for async I/O
    - Consequences: faster collection, lower memory (lazy), but adds complexity (async + multiprocessing coordination)
    - Status: Accepted, Date: 2026-06-08

    ADR-010 (pickle-runner-isolation.md):
    - Context: Each scenario execution must be isolated — step failures in one scenario must not affect others
    - Decision: Per-scenario state machine (ScenarioRun with RunStage transitions); pickle_runner owns step dispatch; Run.create_scenario_run/run.pop_scenario_run manage lifecycle
    - Consequences: guaranteed isolation, clean teardown, but requires explicit state management per scenario
    - Status: Accepted, Date: 2026-06-08

    Both follow ADR template (Context → Decision → Consequences with Positive/Negative/Neutral).
