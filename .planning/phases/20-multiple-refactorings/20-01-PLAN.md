    Create src/pytest_bdd/_ruff/rules/layer_rules.py following the exact blueprint from plugin_patterns.py:

    1. Imports: from __future__ import annotations, ast, sys, tomllib, pathlib.Path, typing.NamedTuple
    2. Violation NamedTuple with path, line (int|None), message
    3. BLQ1301 message format: "BLQ1301: downward import — module {current_module} (layer {current_layer}, order {current_order}) imports {imported_module} (layer {imported_layer}, order {imported_order}). Allowed: {allowed}"
    4. BLQ1302 message format: "BLQ1302: horizontal import — module {current_module} (layer {current_layer}) imports {imported_module} from same layer. Cross-module imports within layer {imported_layer} are forbidden."

    Core logic in LayerRuleVisitor(ast.NodeVisitor):
    - __init__ loads layers.toml at construction via tomllib.loads(Path("docs/architecture/layers.toml").read_bytes())
    - visit_Import / visit_ImportFrom: resolve the imported module's fully-qualified name using path heuristics (base package membership from the layers config's modules list), then check if the import violates layer ordering
    - For each import node, determine current file's layer by matching its module path prefix against layer.modules entries
    - Check: if imported_layer.order >= current_layer.order AND imported not in current_layer.allowed_imports → BLQ1301
    - Check: if imported_layer == current_layer but imported_module.package != current_module.package → BLQ1302 (horizontal cross-package within same layer)
    - Honor the [exceptions] table from layers.toml: if (current_module, imported_module) matches an exception entry, skip violation

    check_file(path) function: parse AST, run LayerRuleVisitor, return violations list.
    main(argv) function: accept target paths (default: Path("src/pytest_bdd")), walk recursively, check each .py file, print violations to stdout, return 1 if violations else 0.

    Critical: the script must work as a standalone module (python -m pytest_bdd._ruff.rules.layer_rules) AND as importable check_file(). Do NOT modify any existing _ruff/rules/ files.
