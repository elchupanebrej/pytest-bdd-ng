<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PYTEST_BDD_GHERKIN_BACKEND env var → _get_parser() | User-controlled env var selects parser backend |
| Go shared library (.so/.dll) → ctypes bridge | Native code loaded via ctypes; malicious .so could execute arbitrary code |
| gherkin-official Python parser → parse() | Third-party parser processes arbitrary Gherkin input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-04 | Tampering | PYTEST_BDD_GHERKIN_BACKEND env var | accept | Env var only selects parser; invalid values default to "auto"; no code injection possible |
| T-20-05 | Elevation of Privilege | _gherkin_go ctypes bridge | mitigate | Go shared library is built from vendored source in this repo; not downloaded from external source. User must explicitly install go-parser extra to enable native code |
| T-20-06 | Denial of Service | BuildGoCommand when Go absent | mitigate | Guard catches FileNotFoundError, logs warning, continues without error — main install succeeds |
| T-20-07 | Tampering | gherkin-official Python parser input | accept | Parser validated by existing test suite; malicious Gherkin input cannot escape Python sandbox |
| T-20-SC | Tampering | npm/pip/cargo installs | mitigate | No new Python packages installed; Go shared library built from vendored source |
</threat_model>
