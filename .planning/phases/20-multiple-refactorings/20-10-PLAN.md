    2. Walk directory tree, process each .py file

    4. For each node, extract docstring (ast.get_docstring)
    5. Parse docstring for `#arch-eval:score=<criterion>=<N>` tags using regex: `#arch-eval:score=(\w+):(\d)`
    6. Build score dict per object: {criterion_name: score_int}
    7. Track objects per module and package for hierarchy

    Output format: writes docs/architecture/OBJECT_MAP.md with:
    - Title and description
    - Summary table: package → average score → object count → scored count
    - Per-package sections: module → object → score breakdown (7 criteria × 0-5)
    - Unscored objects list (objects without tags — scored 0 by default)
    - Overall average across all wave 1 objects

    Script must:
    - Import cleanly as a module (for testing)
    - Have a main() function for CLI invocation
    - Exit 0 if average ≥ 4.0, exit 1 if below (for CI gating)
    - Handle missing docstrings gracefully (score = 0 for all criteria)
    - Skip __pycache__, .pyc files, and test files

    Use stdlib only (ast, pathlib, sys, re, collections). No external dependencies.

    Wave 1 filter: only score objects in these modules:
    - pytest_bdd.__init__
    - pytest_bdd.scenario
    - pytest_bdd.steps
    - pytest_bdd.parsers (and sub-modules)
    - pytest_bdd.hook
    - pytest_bdd.types
