    Create file_size_rules.py following the exact _ruff/rules/ blueprint.

    **BLQ1201 (>400 LOC detection):**
    - For each .py file, count logical lines of code (exclude blank lines and comment-only lines)
    - If LOC > 400, emit BLQ1201 violation
    - Message format: "BLQ1201: {path} has {loc} lines of code (max 400). Consider splitting into a package."

    **BLQ1202 (responsibility cluster detection per D-10):**
    - Parse AST, group top-level class/function definitions by shared import dependencies
    - Algorithm from RESEARCH.md §A1: collect used_names for each top-level ClassDef/FunctionDef, cluster by shared dependency profiles
    - If file has >3 distinct clusters, emit BLQ1202 with split proposal listing cluster members
    - Message format: "BLQ1202: {path} has {n} responsibility clusters. Suggested split: cluster 'X' (classes: [...], functions: [...]), cluster 'Y' (...)"

    Implementation structure (following plugin_patterns.py):
    - Violation NamedTuple
    - FileSizeVisitor(ast.NodeVisitor) — for BLQ1201 (simple LOC count)
    - ResponsibilityClusterVisitor(ast.NodeVisitor) — for BLQ1202 (AST cluster analysis)
    - check_file(path) → list[Violation] — runs both visitors
    - main(argv) → int — CLI with target path arg, default Path("src/pytest_bdd")
