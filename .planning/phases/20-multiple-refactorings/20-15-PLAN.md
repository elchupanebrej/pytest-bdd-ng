  <action>
    Create `src/pytest_bdd/_ruff/rules/init_rules.py` following the exact pattern in `plugin_patterns.py` and `quality_gates.py`:

    **Module header:** docstring with rule codes (BLQ1401, BLQ1402), CI/pre-commit command, exit code convention.

    **BLQ1401 — unjustified re-exports:** Scan `__init__.py` files for `ast.ImportFrom` nodes that re-export symbols (i.e., the import brings names into the init module's namespace and they become part of the package's public surface). If the file contains ANY `ast.ImportFrom` (or `ast.Import`) but does NOT contain a `# init: public-api` or `# init: allow` comment anywhere in the file, emit a WARNING. The check looks for the comment pattern on any line — use string matching on the raw source lines, not AST.

    **BLQ1402 — re-exports without __all__:** If an `__init__.py` contains `ast.ImportFrom` nodes that re-export symbols AND the module-level `__all__` is not defined (no `ast.Assign` targeting `__all__`), emit a WARNING. This prevents accidental export leakage.

    **Exemptions:** Files containing `# init: no-check` anywhere in the source are fully exempt from both rules. Files with NO ImportFrom/Import nodes are automatically clean (not flagged).

    **Implementation structure:**
    - `class Violation(NamedTuple)` with `path: Path`, `line: int | None`, `message: str`
    - `class InitRuleVisitor(ast.NodeVisitor)` with `visit_ImportFrom`, `visit_Import` — records whether imports exist
    - `def check_file(path: Path) -> list[Violation]` — reads source, parses AST, checks comment patterns, returns violations
    - `def check_paths(paths: Iterable[Path]) -> list[Violation]` — walks directories, calls check_file for each __init__.py
    - `def main(argv=None) -> int` — CLI entry, processes args (default: `src/pytest_bdd/`), prints violations, returns 1 if violations found

    **BLQ prefix assignment:** BLQ1401 (unjustified re-exports), BLQ1402 (missing __all__). The 14xx prefix is for init/package hygiene rules.

    **Pre-commit hook:** Insert into `.pre-commit-config.yaml` in the `repo: local` hooks section, after the `typing-rules` hook (after line 96). Use the exact same pattern as existing local hooks:
    ```yaml
    - id: init-rules
      name: init-rules
      entry: >-
        uv run python -m pytest_bdd._ruff.rules.init_rules
        src/pytest_bdd/
      language: python
      additional_dependencies: ["uv"]
      types: [python]
      pass_filenames: false
    ```

    **Test guard:** After creating the rule, verify it detects violations by temporarily running against an un-annotated __init__.py. The rule should produce violations on files with imports but without justification comments. (The full codebase will only pass after Task 2 annotates all files.)
  </action>
