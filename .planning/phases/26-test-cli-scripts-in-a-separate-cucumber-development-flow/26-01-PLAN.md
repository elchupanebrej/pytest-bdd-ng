<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Feature text to subprocess harness | Gherkin command strings cross from feature docs into subprocess execution. |
| Testdir filesystem to CLI scripts | Scenarios create temporary files that CLI commands read and write. |
| Repository scripts to contributor machine | Development scripts run locally and must avoid mutating global user state. |
| Shell-only audit script to native E2E | D-04 forbids direct shell execution in Phase 26 E2E. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01-01 | Tampering | command execution steps | mitigate | Reuse `harness.py` subprocess execution, invoke Python commands per D-01/D-02, and avoid shell=True behavior. |
| T-26-01-02 | Tampering | scenario file fixtures | mitigate | Write mock files only under `testdir.tmpdir` and copy repository assets into the isolated test directory. |
| T-26-01-03 | Denial of Service | shell audit script in native E2E | mitigate | Document the shell audit as an architectural gap and add a static no-bash/no-sh gate per D-04. |
| T-26-01-04 | Repudiation | CLI output verification | mitigate | Assert concrete exit codes, output fragments, and generated files per D-03. |
| T-26-01-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install is introduced by this plan. |
</threat_model>
