# Plan 1: Replace Make & Shell Scripts with Act + Python

## Goal

Eliminate GNU Make and shell script dependencies from the development workflow by replacing them with GitHub Actions
workflows (run locally via `act`) and Python scripts.

## Context

The project used a 445-line GNU Makefile as the human entrypoint for task orchestration. Make targets covered env
checks, test orchestration, Docker/WSL2 cross-platform bridges, linting, docs building, and release checks. Shell
scripts handled ancillary tasks.

Problems: Git Bash required on Windows, fragile cross-platform path handling, no local CI parity, shell scripts harder
to test than Python.

## Tasks

### Task 1: Create GitHub Actions workflows

**Files:** `.github/workflows/{lint,env,tests,docs,release}.yml`

1. `lint.yml` — ruff check, ruff format, custom rules; triggers on push/PR to main + workflow_dispatch
2. `env.yml` — workflow_dispatch with selectable action input (check/install/install-docker/install-browser);
   conditional logic so `check` doesn't install
3. `tests.yml` — 8 jobs (native, unit, integration, contract, e2e, compat, perf, slow) sharing `UV_SYNC_EXTRAS` env var;
   triggers on push/PR to main + workflow_dispatch
4. `docs.yml` — sphinx-build + feature heading validation; triggers on push/PR to main + workflow_dispatch
5. `release.yml` — build + twine check; manual trigger only

**Acceptance Criteria:**

- [x] All 5 workflows created with correct triggers
- [x] `tests.yml` uses shared `UV_SYNC_EXTRAS` env var across all 8 jobs
- [x] `env.yml` conditional logic prevents install on `check` action
- [x] All workflows use `actions/checkout@v4` + `astral-sh/setup-uv@v4` with `enable-cache: true`

### Task 2: Create Python script replacements

**Files:** `scripts/run_messages_coverage_audit.py`, `scripts/docs_build.py`

1. `run_messages_coverage_audit.py` — Python port of bash audit script using `subprocess.run`
2. `docs_build.py` — Python wrapper for `sphinx-build` supporting 9 targets (html, dirhtml, singlehtml, latexpdf, text,
   man, texinfo, epub, changes), default=html

**Acceptance Criteria:**

- [x] `run_messages_coverage_audit.py` replicates bash script behavior
- [x] `docs_build.py` supports all 9 Sphinx targets with proper argument passing
- [x] Both scripts use `pathlib.Path` for path handling
