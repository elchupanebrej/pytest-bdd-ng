<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer shell -> Makefile | local commands execute static Makefile recipes |
| GitHub runner -> Makefile | CI will execute Makefile recipes in hosted runners |
| Makefile -> npm/PyPI tools | recipe invokes external package managers and CLI tools |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | `TOX` command construction | mitigate | Keep commands static; branch only on exact `GITHUB_ACTIONS=true`; preserve `TOX ?=` caller override semantics. |
| T-17-02 | Tampering | `env-install-npm` packages | mitigate | Use exact locked D-08 package names and `--no-save`; do not add package files unless explicitly required later. |
| T-17-03 | Denial of Service | `validate-github-actions` missing tool | mitigate | Guard `act` with `command -v act` and actionable install hint before running validation. |
| T-17-04 | Information Disclosure | `act` workflow validation | mitigate | Run only `act --validate`; do not run workflow jobs or secrets locally. |
| T-17-SC | Tampering | npm/PyPI installs | mitigate | Use packages from Phase 17 research audit; scoped npm packages are locked by D-08 and contract-tested by exact name. |
</threat_model>
