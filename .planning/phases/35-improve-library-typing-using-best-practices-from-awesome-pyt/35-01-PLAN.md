<threat_model>
### Threat Model (STRIDE / ASVS Level 1)

| Threat Category | Potential Scenario | ASVS Control / Mitigation |
|---|---|---|
| **Spoofing** | Executor installs an outdated or malicious local wheel instead of the newly built checkout. | ASVS 12.4.2: Build the wheel with a clean build command (`uv build`) into a clean temporary workspace before every test execution wave. |
| **Tampering** | Malicious alteration of type-check fixtures to falsely pass validation. | ASVS 10.3.2: Fixtures are committed under git version control and assertions verify diagnostic outputs against golden rules. |
| **Denial of Service** | Infinite loops/hanging during mypy or pyright subprocess execution stalls the CI pipeline. | ASVS 11.2.1: Enforce a strict timeout of 180 seconds on all subprocess calls executing static type checkers. |
| **Elevation of Privilege** | Execution of untrusted code inside the validation test runner. | ASVS 12.1.1: The test runner only invokes static checkers (`mypy`, `pyright`) on the fixture modules, never imports or runs them at runtime. |
</threat_model>
