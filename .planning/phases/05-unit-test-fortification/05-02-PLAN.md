## Phase 5 - Wave 1: Model Module Tests

**Objective:** Write comprehensive direct-instantiation unit tests for the three
model modules: `model/run.py` (Run class), `model/scenario_run.py` (ScenarioRun,
RunNode, StepRun), and `model/feature_binding.py` (FeatureRuntimeBinding).
Target >85% line coverage on each. Also migrate existing characterization and
contract tests into `tests/unit/model/` with `@pytest.mark.unit`.

**Why this matters:** Model modules are pure `@define(slots=True)` data classes
with no pytest runtime coupling — direct instantiation is the correct testing
approach (100x faster than testdir). These modules form the core runtime state;
gaps here leave the most critical logic untested.

**Output:** Three new test files in `tests/unit/model/`, existing tests migrated
and marked, coverage >85% on each module.
