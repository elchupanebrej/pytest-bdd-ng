## Phase 5 - Wave 0: Infrastructure Setup

**Objective:** Establish the foundational testing infrastructure: install `pytest-cov`,
register the `unit` marker, add `fail_under = 70` to `.coveragerc`, create shared
conftest with factory fixtures, and scaffold the `tests/unit/` directory.

**Why this matters:** Without these prerequisites, no unit tests can run reliably.
The `unit` marker must be registered before any `@pytest.mark.unit` tests are
written, and shared fixtures eliminate duplication across model test files.

**Output:** Configuration files updated, `tests/unit/conftest.py` with reusable
factory fixtures, directory scaffolding complete.
